# Srikaran K Portfolio

Responsive portfolio built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — page content
- `style.css` — visual design and responsive layout
- `script.js` — mobile menu, footer year, reveal effects, contact form
- `profile.jpg` — your supplied portrait

## Run
Keep all files together and open `index.html` in a browser. No frameworks or build tools are required.

## Contact form
The form opens the visitor's default email application with the message pre-filled. It does not send directly from the website; a backend or form service is needed for direct submissions.

## Projects
No completed projects were supplied, so the site shows an editable placeholder rather than inventing project experience.

## Publish
Upload the files to your GitHub repository and enable GitHub Pages under **Settings → Pages**.
