Srikaran K — Portfolio Website
A personal developer portfolio built with HTML, CSS, and JavaScript.
Features
- Responsive portfolio layout for desktop and mobile
- About Me section
- Skills cards for HTML, CSS, and JavaScript
- Project showcase cards
- Contact section with GitHub profile link
- Mobile navigation menu
- Scroll-reveal animations
- Automatically updated copyright year
Project Structure
Srikaran-Portfolio/
├── index.html
├── style.css
├── script.js
└── profile.jpg.jpeg
Run Locally
1. Download or clone this repository.
2. Keep all four files in the same folder.
3. Open index.html in your browser.
You can also open the folder in Visual Studio Code and use a local development server extension.
Customize
- Content: Edit index.html.
- Design and layout: Edit style.css.
- Interactive behavior: Edit script.js.

Deploy with GitHub Pages
1. Create a public GitHub repository. For the suggested URL https://srikaran153.github.io/, name the repository srikaran153.github.io.
2. Upload index.html, style.css, script.js, and profile.jpg.jpeg to the repository root.
3. In the repository, go to Settings → Pages.
4. Under the build/deployment settings, choose Deploy from a branch, select the main branch and / (root), then save.
5. Wait for GitHub Pages to finish publishing, then open https://srikaran153.github.io/.
The website URL will work after the repository is created and GitHub Pages deployment succeeds.
